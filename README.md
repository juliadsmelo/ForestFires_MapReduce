# ForestFires_MapReduce

Sobre a Base de Dados:
O dataset utilizado neste projeto é o clássico Forest Fires Dataset, coletado no Parque Natural de
Montesinho, nordeste de Portugal. Ele contém 517 registros de ocorrências de incêndios florestais, com 13
variáveis que descrevem condições climáticas, índices do sistema FWI (Fire Weather Index) e a área
queimada.
O Sistema FWI (Fire Weather Index) é um padrão canadense amplamente utilizado para medir risco de
incêndio com base em condições do clima e umidade do combustível. Quatro de seus índices estão
presentes na base: FFMC, DMC, DC e ISI.
